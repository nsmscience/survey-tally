# survey-tally

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 설문 집계기입니다.
`index.html` 파일 하나로 동작하며, 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
붙여넣은 데이터는 브라우저 안에서만 계산하고 어디로도 보내거나 저장하지 않습니다.

## 쓰는 법

1. `index.html`을 브라우저로 엽니다 (GitHub Pages로 내보내도 됩니다. 저장소 맨 위의 `.nojekyll` 참고).
2. 엑셀에서 머리글 줄을 포함해 응답 범위를 복사한 뒤 입력란에 붙여넣습니다.
3. 결과 표가 바로 나타납니다: 문항 / 유효 응답 / 평균 / 빈 응답 / 제외.

## 집계 규칙

- 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖의 값은 제외입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 표시합니다. 유효 응답이 없으면 `-`.

명세에 없어 정한 세부 사항은 [docs/PLAN.md](docs/PLAN.md)에 적어 두었습니다.

## 구조와 시험

- 계산 로직은 `index.html`의 `<script id="tally-logic">`에 화면과 떼어 두었습니다 (`SurveyTally.parseTsv`, `classifyCell`, `formatAverage`, `tally`).
- `test/`의 시험은 이 블록을 꺼내 Node 내장 `node:test`로 실행합니다. 설치할 패키지는 없습니다.

```bash
npm test
```
